# Produit Academy - Staff Portal

This is the teacher and administrative portal for Produit Academy. 

## Features
- **Teacher Onboarding**: Streamlined flow for new teachers to register, select subjects, and set up profiles.
- **Schedule Management**: Tile-based explicit slot selection system for teachers to set their availability.
- **Analytics & Classes**: View upcoming classes and manage student interactions.

## Tech Stack
- Next.js
- React

## Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```
*(Note: Staff portal defaults to port 3004 in `package.json`)*

Open [http://localhost:3004](http://localhost:3004) with your browser to see the result.

## Integration
This platform communicates with the centralized `produit_academy_backend`. Ensure the backend server is running locally when developing.
